## git 소스 올리는 방법
```bash
git status # git 상태 확인
git add 파일명 # git 서버에 올릴 파일 선택
git status # add 가 되었는지 확인. add 된거는 초록색으로 뜸
git commit -m "메시지내용" # 커밋할 메시지
git push origin main # 깃 서버에 올림
git pull --rebase origin main # 깃 서버 최근 버전 내려받기

# https://github.com/smartwolly5-afk/5_final.git 에서 올라갔는지 확인
```
