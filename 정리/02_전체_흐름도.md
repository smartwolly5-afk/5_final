## 2. 판정 흐름 — 위협도를 어디서 가져오나

```mermaid
flowchart LR
    A["트랙 평균 분류 점수<br/>1위 s1, 1·2위 차이 margin"] --> K{"s1 ≥ 0.6 그리고<br/>margin ≥ 0.2 ?"}
    K -->|예| KN["Known<br/>기종 확정"]
    K -->|아니오| F{"같은 계열 점수 합<br/>≥ 0.6 ?"}
    F -->|예| KV["Known_Variant<br/>계열만 확정"]
    F -->|아니오| UN["Unknown<br/>추정 계열만 기록"]
    KN --> S1["사전 F·M·P × 전술 가중치<br/>(구경 결측이면 유형 p75)"]
    KV --> N{"계열 표본<br/>≥ 3종 ?"}
    UN --> N
    N -->|예| S2["계열 상위 25% (p75)"]
    N -->|아니오| S3["유형 상위 25%<br/>(없으면 주력전차 p75)"]
    classDef ok fill:#dcefd5,stroke:#4b7a3f
    classDef warn fill:#efe9f8,stroke:#7a5bb5
    class KN,S1 ok
    class UN,S3 warn
```

| 단계 | 받는 것 | 하는 일 | 넘기는 것 |
|---|---|---|---|
| 판정 (`judge.py:50~62`) | 트랙 평균 top_k | 위 조건 순서대로 검사 | 상태 |
| Known 위협도 (`judge.py:88~97`) | 사전 행 (f·m·p) | T = (wF·F + wM·M + wP·P) / 가중치 합, cope cage 면 P×1.10 | T |
| 대체 위협도 (`judge.py:65~78`) | 계열 또는 유형 | 계열 표본 3종 이상이면 계열 p75, 아니면 유형 p75 → 주력전차 p75 | T, 근거('T-72 계열 상위25%' 등) |

샘플: Tank-01 → Known(T-90, 0.884 / 차이 0.826) · Tank-02 → Known_Variant(T-72 합 0.78) · UNK-001 → Unknown(0.222, 추정 T-90 → 표본 2 → 주력전차 p75).

## 3. 요청 흐름 — 브라우저에서 서버까지 (실제 함수 이름)

```mermaid
sequenceDiagram
    participant B as 브라우저 dashboard.js
    participant F as Flask dashboard/__init__.py
    participant P as pipeline.analyze
    participant S as media · unknown_registry
    B->>F: init() → fetchResult("/api/threats")
    F-->>B: 404 (분석 전)
    B->>F: fetchResult POST /api/analyze
    F->>P: analyze(영상 A), analyze(영상 B)
    P-->>F: AnalysisResult (+ 내부 _track)
    F->>S: _attach → track_crop, registry.record
    S-->>F: crop_url, unknown_group_id
    F-->>B: _respond → JSON (+ videos, video)
    B->>B: load → render → renderBoxes · renderTable · renderPanelA · renderMap → renderPanelB
```

| 단계 | 받는 것 | 하는 일 | 넘기는 것 |
|---|---|---|---|
| `init` (`dashboard.js:35`) | 페이지 열림 | 버튼 연결, 지도 준비, 마지막 결과 요청 | GET `/api/threats` |
| `analyze` 라우트 (`dashboard/__init__.py:96`) | POST 본문 (없으면 mock A·B) | 영상마다 `pipeline.analyze`, 오류면 400 | 계산 결과 |
| `_attach` (`dashboard/__init__.py:55`) | 계산 결과 | crop 저장, Unknown 레지스트리 저장, 내부 필드 제거 | 화면용 결과 |
