# 03. 사용 프로그램·라이브러리

**라이브러리**(library) = 남이 만들어 둔 기능 묶음. 가져다 쓰면 직접 짜지 않아도 됩니다.
버전은 `requirements.txt` 기준이고, 괄호 안은 이 PC 에 실제 설치된 버전입니다.

## 화면 (브라우저)

| 이름 | 버전 | 한 줄 설명 | 우리 코드에서 쓴 곳 | 왜 썼는지 |
|---|---|---|---|---|
| HTML / CSS / JavaScript | — | 웹 화면 기본 언어 | `dashboard/templates/`, `dashboard/static/` | 별도 프레임워크 없이 가볍게 |
| Leaflet | 1.9.4 (CDN) | 웹 지도 라이브러리 | `index.html:9`, `:179`, `unknowns.html:8`, `:54`, 사용 `dashboard.js:406~447` | 추정 위치·군집 원 표시 |
| OpenStreetMap | 타일 서버 | 무료 지도 그림 | `dashboard.js:410`, `unknowns.js:17` | 지도 배경 (인터넷 필요) |
| Pretendard | 1.3.9 (CDN) | 한글 글꼴 | `index.html:8`, `report.html:7`, `unknowns.html:7`, `templates/dictionary/base.html:8` | 한글 가독성 |
| Lucide 아이콘 경로 | — | 선 아이콘 모양 | `ui.py:1~44` (SVG 로 직접 넣음) | 외부 파일 없이 아이콘 |

> CDN(인터넷으로 라이브러리 파일을 받아 오는 곳)을 쓰므로 **인터넷이 없으면 지도·글꼴이 안 보일 수 있습니다**. 지도는 실패하면 "지도를 불러올 수 없음"을 표시합니다 (`dashboard.js:402~412`).
