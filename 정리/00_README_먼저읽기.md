# 정리 폴더 — 먼저 읽기

이 폴더는 **발표자 한 명이 이 폴더만 보고 PPT 를 만들고 발표·질의응답까지** 할 수 있도록 TANK 위협도 대시보드 코드를 정리한 것입니다.
모든 내용은 실제 코드(`dashboard` 브랜치, 커밋 `443c077` 이후)를 읽고 썼고, 숫자는 샘플(`static/mock_frames/`)을 실제로 실행해서 얻은 값입니다.

## 3줄 요약

1. 영상에서 탐지한 전차를 **기종이 확실한 정도(Known / 계열만 확정 / 미확인)** 로 나누고, 전차 사전 DB 값으로 **전차 1대 위협도**를 계산합니다.
2. 같이 움직이는 전차 무리(**군집**)의 규모와 가장 위험한 전차로 **대응단계 1~4** 를 정하고, 판단 이유를 **근거 태그**로 보여 줍니다.
3. 미확인 전차는 영상이 달라도 **같은 기종으로 보이면 한 그룹**으로 쌓아 두고, 자주·최근에 나온 위험한 그룹부터 순위를 매깁니다.

> **현재 상태 (중요)**: 탐지 모델(YOLO26·DINO)은 아직 연결 전이라 **mock JSON**(모델 결과를 흉내 낸 샘플 파일)을 넣어 동작합니다.
> 여러 임계값은 `TODO`(근거 미정, 임시값)입니다. 발표 때 이 점을 분명히 말하세요 → `12_한계와_향후계획.md`.

## 실행 방법 (Windows PowerShell)

```powershell
# 1) 패키지 설치 (저장소 폴더에서)
pip install -r requirements.txt

# 2-A) MySQL 이 있을 때: .env 에 DB 접속 정보를 넣고 사전·위협도 테이블 만들기
python init_db.py            # tank_specs 테이블 생성
python load_xlsx.py          # tank_dictionary_v2.xlsx → tank_specs (369행)
python sync_threat_db.py     # 위협도 테이블(tank_threat 등) 계산·저장

# 2-B) MySQL 없이 데모: 위협도 값은 dashboard/threat/demo_seed.json, 레지스트리는 SQLite 파일
$env:TANKLAB_DEMO = "1"

# 3) 서버 실행 → 브라우저에서 http://127.0.0.1:5000/
python app.py

# 4) 테스트
python -m pytest tests dashboard/tests -q
```

- 대시보드 첫 화면이 열리면 자동으로 샘플 영상 A·B 를 분석합니다. 위쪽 **mock_video_A / mock_video_B** 탭으로 전환합니다.
- 상단 메뉴 **미확인** = 미확인 그룹 순위(`/unknowns`), **사전** = 전차 제원 사전(`/dictionary`).

## 위치 표기 규칙

- 함수·설정값 위치는 `파일:줄` 로 적습니다. 예: `judge.py:81` = `dashboard/threat/judge.py` 81번째 줄, `pipeline.py:61~71` = 54~64줄.
- 같은 이름 파일이 둘이라 이렇게 구분합니다: **`config.py` = `dashboard/threat/config.py`(대시보드 설정값)**, 저장소 루트의 DB 설정 파일은 **`./config.py`**.
  **`__init__.py` = `dashboard/__init__.py`**.
- 줄 번호는 커밋 `443c077` 기준입니다. 코드를 고치면 바뀔 수 있으니 `10_코드_라인별_설명/_생성기/check_refs.py` 로 확인하세요.
