## 파일별 역할과 "고치면 무엇이 바뀌나"

| 파일 | 역할 | 이 파일을 고치면 |
|---|---|---|
| `dashboard/threat/config.py` | 임계값·가중치·계수 | **계산 결과 전체**(위협도, 판정, 단계, 그룹 매칭, 순위)가 바뀜. 가장 먼저 볼 파일 |
| `dashboard/threat/pipeline.py` | 응답 JSON 조립 | 화면에 가는 필드, 랭킹 정렬, 근거 태그 문구, 카운터, 경보 |
| `dashboard/threat/core.py` | 대응단계 계산 | 제대 판정, 군집점수·단계, 하한 규칙, v1 점수 |
| `dashboard/threat/track.py` | 트랙 집계 | 지휘전차·cope cage 판정, 분류 평균, 임베딩, crop 후보 |
| `dashboard/threat/judge.py` | 판정·위협도 | Known/Variant/Unknown 결과, 위협도 출처, cope cage 보정 방식 |
| `dashboard/threat/dictdb.py` | 사전 위협도 읽기 | 계열·유형 p75 값, DB/seed 전환 |
| `dashboard/threat/label_map.json` | 라벨 매핑 | 어떤 분류 라벨이 어떤 기종·계열로 인정되는지 (없는 라벨은 Unknown) |
| `dashboard/__init__.py` | API 주소 | 주소·오류 코드, 영상 전환, crop·레지스트리 저장 시점 |
| `dashboard/unknown_registry.py` | 레지스트리 | 그룹 묶는 방식, 집계, 순위, crop 정리 |
| `dashboard/media.py` | crop 저장 | 자르는 범위(여백), 저장 위치 |
| `dashboard/static/dashboard.js` | 화면 동작 | 표·박스·패널·지도 그리기, 버튼 동작 |
| `dashboard/templates/dashboard/index.html` | 화면 뼈대 | 화면 배치, 버튼·영역 |
| `dashboard/static/dashboard.css`, `static/style.css` | 모양 | 색·크기·배치 (단계 색은 `style.css` 의 `--stage1~4`) |
| `schema_threat.sql` | 테이블 정의 | DB 구조 (바꾸면 기존 DB 와 맞추는 작업 필요) |
| `threat_calc.py`, `sync_threat_db.py` | 사전 위협도 계산·저장 | `tank_threat` 의 F·M·P·T 값 → 대시보드 Known 위협도와 p75 |
| `response_level.py`, `threat_api.py` | DB 엔진 | `/api/threat` 결과 (대시보드 화면과는 별개) |
| `static/mock_frames/*.json` | mock 입력 | 데모 화면에 나오는 표적·숫자 |
| `dictionary.py`, `templates/dictionary/` | 사전 화면 | `/dictionary` 화면 |
