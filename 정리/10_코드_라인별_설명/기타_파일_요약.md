# 기타 파일 요약 (함수 단위)

핵심 파일 외 나머지입니다. 함수별 줄 번호·입력·호출 위치는 `../05_함수_목록.md` 표에 있습니다.

## 파이썬

### `dashboard/threat/dictdb.py` — 사전 위협도 조회 (93줄)
- `data()` (34~46): 처음 한 번 DB 에서 `tank_threat` 전체(369행)와 `type_threat_summary` 를 읽어 메모리에 둡니다. DB 가 없거나 비어 있으면 `demo_seed.json`(샘플 계열 14종)을 씁니다.
- `tank(tank_id)` (54~56): 기종 1행. `family_stats(family, tactic)` (63~69): 계열 안 계산 가능한 기종들의 T·F·M·P 상위 25%와 표본 수. `family_type_group` (72~75): 계열의 대표 유형. `type_p75` (78~80): 유형 p75.
- `make_seed()` (83~89): `python -m dashboard.threat.dictdb --seed` 로 seed 파일 다시 만들기.

### `dashboard/media.py` — crop 저장 (59줄)
- `frame_file` (24~29): `static/` 안의 실제 파일만 허용 (외부 입력 경로로 다른 파일을 읽지 못하게).
- `crop_box` (32~36): bbox 각 변에 폭·높이의 10% 여백, 프레임 밖은 잘라 냄.
- `save_crop` (39~49): Pillow 로 잘라 `static/<경로>` 에 저장. 원본이 없으면 경고 후 None.
- `track_crop` (52~59): 상세 패널용 대표 crop (`track_crops/<영상>/<표적>_<프레임>.jpg`), 이미 있으면 다시 자르지 않음.

### `threat_db.py` — DB 공통 함수 (74줄)
- `demo()` (14): `TANKLAB_DEMO=1` 인지. `connect()` (18~24): MySQL 또는 SQLite 연결.
- `query`, `execute` (31~49): SELECT → 딕셔너리 목록, INSERT/UPDATE → 새 행 번호. SQLite 면 `%s` 를 `?` 로 바꿈 (`_sql`).
- `execute_all` (52~65): 여러 문장을 한 트랜잭션(모두 성공하거나 모두 취소)으로.
- `init_schema` (68~74): `schema_threat.sql` 실행 (SQLite 면 자동 증가 문법만 바꿈).

### `threat_calc.py` — 사전 → F·M·P·T (289줄)
- 텍스트 해석: `gun_cal` 구경, `gun_len` 구경장, `gen_of` 세대, `armor_of` 장갑 계수 (65~100).
- `build_inputs` (103~251): 계산 입력값 7가지를 정하고 빠진 값을 계열 중앙값 → 구경 구간 → 유형 → 전체 중앙값 순으로 채움, 출처(`*_src`)와 신뢰도 상·중·하 기록.
- `py_threat` (254~263): F·M·P·T_1~T_10 계산 (06번 문서 1·2절). `compute` (269~279): 기준전차 M1A1 을 계수 값으로 고정해 정확히 1.0/100.
- `coefs_from_sheets` (282~289): 계수·가중치 엑셀 시트 읽기.

### `sync_threat_db.py` — 위협도 테이블 재계산 스크립트 (101줄)
`python sync_threat_db.py` → 테이블 생성 → 계수가 비었으면 엑셀에서 1회 채움(`seed`) → 사전 읽기 → `compute` → `tank_threat`·`type_threat_summary` 를 한 트랜잭션으로 교체 (`sync`, 60~93). 유형 p75 는 pandas `quantile(0.75)` (81).

### `threat_api.py` — `/api/threat` (61줄)
`response_level` 을 HTTP 로 노출. `_body` 는 JSON 객체만 허용(아니면 400), ValueError → 400, LookupError → 404.

### `dictionary.py` — 전차 사전 화면 (498줄)
- `load_tanks` (26): `tank_specs` 전체. 값 표시 도우미(`text`, `to_number`, `fmt_num`, `display` …, 113~162).
- `home` (223~242): 검색·필터·국가 목록. `country_page` (254): 국가별 목록·통계.
- `quant_threat` (279~283): 사전 화면 위협도 = 100 × (F+M+P)/3 (전술 가중치 없음).
- `tank` (478~489): 상세 페이지 (제원 표, 사진 `tank_image`, 위협도 패널 `threat_panel`).

## JavaScript

### `dashboard/static/unknowns.js` — 미확인 화면 (94줄)
- `init` (14~47): 지도 준비 → `/api/unknowns` → 순위 표 → 1위 자동 선택.
- `show(id)` (49~92): `/api/unknowns/<id>` → 제목·상태·칩·요약(병합 후보 포함)·crop 갤러리·출현 위치 지도. 기다리는 사이 다른 그룹을 고르면 이전 응답은 버림.
