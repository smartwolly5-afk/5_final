## 버튼별 동작 흐름

### 단계 조정 (지휘관 판단으로 전체 단계 바꾸기)
1. '단계 조정' 클릭 → 1~4단계 버튼 줄이 펼쳐짐 (`dashboard.js:38`, `togglePicker`).
2. 단계 클릭 → 화면 상태 `commanderStage` 에 저장 (`dashboard.js:41~47`). **서버 호출 없음**, 계산값은 그대로.
3. 사다리에 선택 단계는 칠하고 AI 권고는 점선, 'AI 권고 3단계 → 지휘관 결정 1단계' 문구 (`renderPanelA`).
4. 보고서 출력 시 `?stage=1` 로 함께 전달됨. 새 분석이 오면 조정은 풀립니다 (`dashboard.js:88`).

### 전술 선택 (군집 전술 지정)
1. '전술 선택' → 군집·전술(1~10, 자동) 고르기 → '적용' (`dashboard.js:291` `applyTactic`).
2. `PATCH /api/clusters/C-1/tactic {"tactic": 3}` → 서버가 그 군집 전차 위협도를 새 가중치로 다시 계산 (`dashboard/__init__.py:142` → `pipeline.analyze(tactic_overrides=…)`).
3. 응답으로 화면 전체 갱신. 군집 카드 전술이 주황 '대전차 (지정)'. 예: 영상 A → S 88.9 → 94.1.

### 지휘전차 지정·해제
1. 상세 패널의 '지휘전차 해제'/'지휘전차로 지정' 클릭 (`dashboard.js:375` `toggleCommander`).
2. `PATCH /api/threats/Tank-01/commander {"is_commander": false}` (탐지 규칙과 같은 값으로 되돌릴 때는 null).
3. 서버 재계산: 지휘전차가 없어지면 군집 전술이 ⑩ → ① 로 바뀌어 점수가 달라짐. 태그 '지휘전차 해제 (지휘관)'.

### 확정·병합·기각 (미확인 그룹)
- **아직 구현되지 않았습니다 (TODO)**. DB 에는 `unknown_group.status`, `confirmed_tank_id`, `merged_into`, `unknown_action` 테이블이 준비되어 있고, `/unknowns` 화면에는 버튼이 없습니다.
- 계획 (작업 지시 6장): 확정 = tank_id 지정 → 이후 같은 그룹 매칭 표적은 Known 취급, 병합 = 출현 기록·crop 이동 후 centroid 재계산, 기각 = 오탐 처리, 모든 조치는 `unknown_action` 에 기록.

### 보고서 출력
1. '보고서 출력' → 새 탭 `/report` (지휘관 조정 단계가 있으면 `?stage=N`) (`dashboard.js:302`).
2. 서버가 지금 영상의 결과로 HTML 보고서를 만듦 (`dashboard/__init__.py:217`).
